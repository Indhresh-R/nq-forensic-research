This report-level pointer exists so program documentation has a consistent entry point.

## Status vocabulary

- **SUPPORTED** — the report's own claim held under its stated test.
- **NOT SUPPORTED / KILL / CLOSED** — the tested claim did not survive its stated gate.
- **INCONCLUSIVE** — evidence was insufficient or explicitly left unresolved.
- **NOT TESTED / UNTESTED** — no result was produced; this is not a negative result.

A state or information finding is not automatically an executable trading edge. Read the underlying dossier for the exact claim, sample, split, and cost model.
