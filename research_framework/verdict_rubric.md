# Verdict Rubric

| Code | Meaning |
|------|---------|
| **A** | Validated edge under hostile gates (as claimed: direction, timing, or economics) |
| **A\*** | Validated **scientific** finding that is **not** an executable standalone strategy (e.g. HIGH state detector) |
| **B** | Weak / inconclusive leftovers; do not promote |
| **C** | No demonstrated edge; kill family |
| **D** | Invalid / contaminated (lookahead, broken data, non-causal definition) |

## Kill rules

- Kill the **family**, not one parameter setting
- Do not rescue with VWAP/SMT/levels/options stacks after a clean fail
- Document **why** in one paragraph
