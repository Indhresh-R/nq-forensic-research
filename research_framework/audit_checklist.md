# Hostile Audit Checklist

Copy into each new dossier before promotion:

- [ ] Signal uses only `t <= T`
- [ ] Outcomes start at next open
- [ ] Thresholds frozen on IS only
- [ ] No grid search for the promoted rule
- [ ] Val and OOS scored once after freeze
- [ ] 2025 / 2026 separated
- [ ] Multi-clock or multi-horizon check
- [ ] Same-TOD or unconditional baseline where relevant
- [ ] Ambiguity policy documented
- [ ] Overlap / clustering documented if multiple signals/day
- [ ] External data lag documented
- [ ] Failure mode written in `conclusion.md` (not just "failed")
